# الخليل للصغار

> مساحة ترفيهية وتربوية لأطفال الخليل — حكايات، ألعاب ذهنية، وأنشطة إبداعية.

صفحة ترحيبية ثابتة (static) ما بتحتاج أي سيرفر أو أدوات بناء.

## البنية

```
.
├── index.html      # الصفحة الرئيسية
├── css/
│   └── style.css   # التصميم كامل (تطريز + حجر)
├── js/
│   └── main.js     # التحية، التاريخ، اللعبة، مبدّل التطريز
└── README.md
```

## التشغيل

أي طريقة من هالتين:

```bash
# 1) فتح مباشر
start index.html

# 2) سيرفر محلي (أفضل — عشان الخطوط و CORS)
python -m http.server 8000
# ثم افتح http://localhost:8000
```

## المزايا

- **تحية حسب الوقت** — بتتبدّل حسب ساعة الجهاز
- **التاريخ بالعربية** — بالتاريخ الهجري/الميلادي حسب إعدادات المتصفح
- **لعبة جمع النجوم** — ١٠ نجوم = وسام، وأفضل نتيجة محفوظة في المتصفح
- **مبدّل التطريز** — ثلاث لوان (أحمر / أزرق / أخضر) مربوطة في `localStorage`
- **متجاوب** — من ٣٢٠ بكسل لحد الشاشات الكبيرة
- **يحترم `prefers-reduced-motion`** — بيوقف كل الحركات لمن يحتاج

## التصميم

الهوية البصرية **"Stone & Thread"** — مستوحاة من التطريز الفلسطيني وحجر الخليل القديم.

| المتغيّر | القيمة | الاستخدام |
|---|---|---|
| `--stone` | `#F7F1E4` | خلفية حجرية دافئة |
| `--ink` | `#241C2E` | الحبر الأساسي |
| `--thread-1/2/3` | قرمزي / نيلي / زيتوني | خيوط التطريز |
| `--gold` | `#D4A32C` | الذهب |

الخطوط: **Lalezar** للعناوين، **Marhey** للنصوص، **Aref Ruqaa** للتحيات.

## النشر

